## 推荐学习顺序

先理解 Azure 控制面、治理边界与可靠性目标，再学习网络、身份和工作负载；随后进入监控、日志、资源清单与恢复；最后学习 Terraform 状态、流水线、混合网络和成本治理。完整的 23 讲问题目录见课程目录。

## 如何选择实验

每章和实验 README 会标明练习类型：

- **本地可执行实验**使用合成输入或本地服务，按 README 安装工具并执行。它验证的是该实验模型所覆盖的行为。
- **Azure 只读练习**会访问 Azure 订阅或工作区。先确认目标租户、订阅、资源范围和读取权限，再执行命令。
- **Azure 现场练习**涉及资源创建、配置或删除。需要独立的资源范围、权限、费用评估、运行时限和清理步骤。
- **企业设计练习**用于推演架构或服务端设置，不代表云端配置已经部署或验证。

先确认实验类型，再查看它自己的依赖、权限和清理要求。没有列出实际运行记录的命令和配置应视为文档示例。

## 学习边界

本地实验帮助检验因果推理，不证明 Azure 平台的实时行为。章节会区分文档机制、配置示例、本地观测与云端观测；目前七条 KQL 模板没有在真实 workspace 执行。更多课程与验证限制见根目录说明。
